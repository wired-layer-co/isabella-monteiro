# Fontes das imagens

Todas as fotografias são material real fornecido pela cliente. Nenhuma imagem foi gerada por inteligência artificial.

## Fotos do acervo antigo

- `black-tie-*.webp`, `delirio-*.webp`, `divina-tragicomedia-*.webp`, `ecos-*.webp`, `historia-*.webp`, `teicoscopia-*.webp`: extraídas de `PORTFOLIO DE ATRIZ/portifilio antigo - canvas.com - pdf - PORTFOLIO ISABELLA MONTEIRO.pdf`.
- As imagens de Teicoscopia, cuja fonte no PDF tinha cerca de 300 px de largura, passaram por restauração de resolução e artefatos para uso em tela cheia.

## Peças do Canvas

- `pill-audiovisual.png` e `pill-teatro.png`: recortes em alta resolução da página 1 do PDF `SITE PORTFOLIO.pdf` (Canva), preservando o rabisco e o texto originais dos botões. Foram extraídos a 300 DPI e tiveram o fundo normalizado para `#FBFBF8`.
- `public/fonts/biro-script-plus.woff2`: fonte Biro Script Plus embutida no PDF do Canva, extraída e convertida para WOFF2 para os títulos de pincel.
- A fonte Poppins é servida pelo pacote `@fontsource/poppins`.

## Observação

Os arquivos `.webp.json` antigos preservam a procedência das imagens do primeiro pacote. As novas imagens são documentadas por este arquivo.
