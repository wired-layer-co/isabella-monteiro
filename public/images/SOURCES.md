# Fontes das imagens

Todas as fotografias foram extraídas do arquivo fornecido pela cliente:

`PORTFOLIO DE ATRIZ/portifilio antigo - canvas.com - pdf - PORTFOLIO ISABELLA MONTEIRO.pdf`

Os arquivos foram redimensionados e convertidos para WebP para uso na web. As duas imagens de Teicoscopia, cuja fonte no PDF tinha cerca de 300 px de largura, também passaram por restauração de resolução e artefatos para uso em tela cheia. Os nomes descrevem o trabalho ou o uso no site.
